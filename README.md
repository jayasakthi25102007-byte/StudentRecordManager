# Student Record Manager

A console-based Java mini project to manage student records — built while learning core Java and Object-Oriented Programming (OOP) concepts.

## Features
- Add a new student (auto-generated ID, name, age, marks)
- View all student records
- Update an existing student's details by ID
- Delete a student record by ID
- Simple menu-driven interface using loops and switch-case
